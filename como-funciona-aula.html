Cómo funciona el Aula Virtual

NeuralMente — Arquitectura simplificada del sistema de enseñanza

👤 Alumno escribe en el chat
Hace preguntas, responde ejercicios, entrega retos
💬 Interfaz del Tutor (Next.js)
La pantalla del chat que ve el alumno en el website
📄 Guión
El documento Track 1 que construimos — le dice a Claude qué enseñar
🤖 Claude API
Lee el guión + el historial + el mensaje del alumno → genera la respuesta del tutor
💾 Historial
Conversaciones guardadas en Supabase — el tutor recuerda todo
⭐ Sistema de XP y Progreso
Claude detecta si el alumno completó la lección → suma XP automáticamente → desbloquea el siguiente módulo
📊 Dashboard
XP acumulado, nivel y badges del alumno
🔓 Módulo siguiente
Se desbloquea automático al completar el reto
🏅 Certificado
Se genera solo al terminar el track
Stack: Next.js — el website Claude API — el tutor Supabase — la base de datos Stripe — los pagos

En lenguaje simple: el alumno escribe en el chat → Claude lee el guión del módulo + todo el historial de la conversación → responde como tutor personalizado → si el alumno completó la lección, el sistema le suma XP y desbloquea lo siguiente. Todo automático. Sin que tú tengas que hacer nada.
